Oásis Beauty

Plataforma de estética de alto padrão com catálogo, carrinho e agendamento

Ver site ao vivoCódigo no GitHub

Objetivo do projeto

Uma plataforma sofisticada para o mercado de estética de alto padrão. Em vez de um site institucional comum, o visitante navega pelos tratamentos, monta um carrinho de serviços e finaliza a reserva de forma fluida, preferencialmente pelo WhatsApp.

Tecnologias

  • React
  • TypeScript
  • Tailwind CSS
  • Vite
  • React Router
  • Context API
  • Vercel

O que foi entregue

  • Catálogo visual de tratamentos e procedimentos de estética avançada
  • Carrinho inteligente de serviços com cálculo automático de totais
  • Persistência dos itens escolhidos (o cliente não perde o que selecionou)
  • Fluxo de agendamento com formulário de captura de leads
  • Integração direta com WhatsApp para finalização da reserva
  • Assistente virtual (chatbot) para tirar dúvidas frequentes
  • Design editorial sofisticado com efeitos modernos (glassmorphism)
  • Experiência 100% responsiva (celular, tablet e desktop)

Mais telas

Destaques

  • Design sofisticado alinhado a marcas de alto padrão
  • Do interesse à reserva em poucos cliques
  • Performance otimizada e carregamento rápido
  • Pensado para o celular, onde a maioria dos clientes acessa

Solarium Resort

Sistema de reservas de acomodações de luxo com cálculo de estadia em tempo real

Ver site ao vivoCódigo no GitHub

Objetivo do projeto

Uma experiência digital completa para um resort de alto padrão. O visitante se sente em um ambiente de luxo já na primeira tela, explora os quartos, escolhe datas e hóspedes e simula a reserva sem sair da página.

Tecnologias

  • React
  • TypeScript
  • Tailwind CSS
  • Vite
  • Vercel

O que foi entregue

  • Home com apresentação visual impactante do resort (carrossel de imagens)
  • Catálogo detalhado de acomodações exclusivas
  • Carrinho de reservas com gerenciamento dos quartos selecionados
  • Seleção dinâmica de adultos e crianças por quarto
  • Cálculo automático do valor da estadia com base nas datas
  • Valores atualizados em tempo real conforme as opções mudam
  • Layout 100% responsivo para celular, tablet e desktop

Mais telas

Destaques

  • Fluxo de reserva intuitivo, simulando um booking real
  • Cálculos automáticos que passam transparência
  • Visual de luxo alinhado à proposta do resort
  • Utilizável no celular, essencial para quem pesquisa hospedagem em movimento

The Sweet Lab Chocolate

E-commerce interativo de chocolates artesanais com filtros e checkout

Ver site ao vivoCódigo no GitHub

Objetivo do projeto

Uma experiência de compra leve e bonita para uma marca artesanal de chocolates finos. O desafio era um catálogo prazeroso de navegar no celular, com busca rápida, filtros úteis e um checkout direto ao ponto.

Tecnologias

  • React
  • TypeScript
  • Vite
  • Context API
  • CSS Modular
  • Vercel

O que foi entregue

  • Catálogo de produtos com visual atrativo e organizado
  • Busca em tempo real pelo nome do produto
  • Filtros por categoria e ordenação (preço, favoritos, mais vendidos, alfabética)
  • Carrinho global: adicionar, remover e manter os itens selecionados
  • Checkout simples e direto, com resumo do pedido
  • Integração com o Instagram no rodapé
  • Grade de produtos pensada para o celular, sem rolagem cansativa

Mais telas

Destaques

  • Compra rápida e agradável, especialmente no mobile
  • Busca e filtros que levam ao produto certo em segundos
  • Checkout sem enrolação, ideal para converter
  • Visual limpo e apetitoso, coerente com a marca
