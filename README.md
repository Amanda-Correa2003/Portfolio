# Portfólio — Amanda Corrêa Machado

Site estático (HTML + CSS puro). Não precisa instalar nada.

## Estrutura
portfolio/
├── index.html      <- página inteira (HTML e CSS)
├── assets/         <- todas as imagens (prints dos projetos)
└── README.md       <- este arquivo (pode apagar)

## Ver no computador
Dê dois cliques no index.html. Ele abre no navegador.
(Mantenha a pasta assets ao lado do index.html, senão as imagens somem.)

## Colocar no ar na Vercel
1. Crie um repositório no GitHub (ex.: "portfolio") e envie esta pasta com index.html e assets/.
2. Na Vercel: Add New > Project > importe o repositório.
3. Framework Preset: "Other". Não precisa de Build Command nem Output Directory. Clique em Deploy.
4. Para mudar o endereço: Settings > Domains.
